## Project Overview

The Mini Hospital Emergency Management System is a Java console-based application developed to simulate the basic operations of a hospital emergency unit.

The system allows users to manage patient records, emergency treatment queues, completed treatment histories, and patient visit histories using different data structures. The project demonstrates the practical application of fundamental data structures in a real-world scenario.

---

## Objectives

The main objective of this project is to implement and demonstrate the use of:

- Binary Search Tree (BST)
- Queue
- Stack
- Singly Linked List

within a hospital emergency management environment.

---

## Data Structures Used

### 1. Binary Search Tree (BST)

The BST is used to manage patient records.

Operations implemented:

- Insert a new patient
- Search a patient by Patient ID
- Delete a patient
- Display all patients using inorder traversal

Patient information includes:

- Patient ID
- Patient Name
- Age
- Contact Number
- Medical Condition

---

### 2. Queue

The Queue is used to manage emergency patients waiting for treatment.

Operations implemented:

- Enqueue (Add patient to queue)
- Dequeue (Treat next patient)
- Display waiting patients
- Empty queue handling

The queue follows the FIFO (First In First Out) principle.

---

### 3. Stack

The Stack is used to store completed treatment records.

Operations implemented:

- Push (Add treatment record)
- Pop (Remove latest treatment record)
- Display treatment history
- Empty stack handling

The stack follows the LIFO (Last In First Out) principle.

---

### 4. Singly Linked List

Each patient maintains a linked list of previous hospital visits.

Operations implemented:

- Add visit
- Search visit
- Remove visit
- Display visit history

Visit information includes:

- Visit ID
- Visit Date
- Doctor Name
- Diagnosis
- Treatment

---

## Main Features

- Register new patients
- Search patient records
- Delete patients
- Display all patients in ascending Patient ID order
- Add patients to emergency queue
- Treat patients using FIFO order
- Record completed treatments
- View treatment history
- Manage patient visit history
- Search and remove patient visits
